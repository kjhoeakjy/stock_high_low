# stock_high_low — 상한가 예측

국내주식(코스피·코스닥) 상한가 후보를 매 영업일 확률·근거와 함께 표시. 투자 권유 아님.

화면: https://kjhoeakjy.github.io/stock_high_low/

## 일과

1. 평일 07:20(한국시간) GitHub Actions `상한가 예측` 워크플로 실행.
2. 수집(`stock.collect`, `stock.collect_text`): 네이버 금융 전 종목 일봉(2019~)·투자자별 순매수(2022~)·업종·테마·공시 제목(2014~)·뉴스 제목(2년), 야후 해외지수·환율, DART 전일 공시.
3. 학습·검증(`stock.run`): 230여 개 변수로 LightGBM 상한가 모델 학습. 최근 12개월은 매월 그 이전 자료만으로 학습·예측하는 워크포워드 검증으로 적중률과 확률 보정표 산출.
4. 리포트(`stock.report`): 전 종목 점수, 상위 후보의 근거(기여 변수), 뉴스·공시, Claude 뉴스 판정(호재·악재 한 줄)을 `docs/latest.json`에 기록 후 커밋. 전일 예측은 실제 결과로 채점해 `history/`에 보존.
5. 08:30 이전 화면 갱신.
6. 장중(08:55~15:45) 5분 간격 `장중 실시간` 워크플로가 시세를 `live` 브랜치에 기록. 화면 '실시간' 탭이 이를 표시.

## 장중 레이더 (PC)

```
python stock/radar.py
```

표준 라이브러리만 사용. 브라우저에 http://localhost:8787 표시. 7초 간격으로 네이버 시세 기준 상한가 잔여 거리·진입·이탈·거래대금 표시. 장전 후보는 ★ 표시.

## 파일

| 파일 | 역할 |
|---|---|
| `common.py` | HTTP, 경로, 숫자 파싱 |
| `collect.py` | 시세·수급·업종·테마·해외지수·DART 수집 |
| `collect_text.py` | 공시·뉴스 제목 수집(증분 캐시) |
| `features.py` | 가격·거래량·수급·시장·업종·테마·달력 변수와 라벨 |
| `text_features.py` | 공시·뉴스 제목 키워드 변수 |
| `model.py` | LightGBM 학습, 워크포워드 검증, 등온 보정 |
| `report.py` | 당일 후보·근거·채점 JSON |
| `llm.py` | Claude 뉴스 판정 (ANTHROPIC_API_KEY 없으면 생략) |
| `live.py` | 장중 시세 수집(Actions) |
| `experiment.py` | 모델 설정 비교 실험(Actions 병렬) |
| `radar.py` | 장중 레이더(PC) |
| `../docs/index.html` | 화면 |

수집 데이터는 `stock-data` 브랜치에 매일 덮어씀(저장소 본문에 미포함). 수급·뉴스 캐시는 Actions 캐시에 보관.

## 라벨과 한계

- 상한가 = 익영업일 종가 등락률 ≥ +29.5%(수정주가 오차 허용). 하한가 예측은 미수행(개인이 활용할 수단 없음). 장중 도달 후 이탈은 별도 집계.
- 상한가는 종목·일 단위 약 0.2%의 희귀 사건. 후보 대부분은 미적중. 화면의 '동일 구간 적중률'이 실제 기대치.
- 전일 종가·야간 해외시장까지 반영. 장중 사건은 실시간 탭과 레이더로 확인.
- KRX 정보데이터시스템·KIND는 Actions에서 차단. 유통주식수·시장경보 지정 내역 미반영.
